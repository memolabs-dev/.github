# Memo Labs — GitHub automation

Dépôt de gouvernance GitHub pour l'organisation [memolabs-dev](https://github.com/memolabs-dev).

La migration de l'ancien compte technique `drop-agent-bot` vers une GitHub App dédiée est documentée dans [docs/github-app-migration.md](docs/github-app-migration.md).

Le workflow [app-auth-smoke.yml](.github/workflows/app-auth-smoke.yml) est **manuel**, non destructif, et vérifie l'authentification de la future application après son enregistrement.

**13 octobre 2026 : phase préparatoire uniquement.** Le compte technique existant et les workflows de production restent inchangés. La nouvelle GitHub App n'est pas encore enregistrée ou installée.
