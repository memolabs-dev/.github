# Memo Labs

**Independent product engineering and open-source developer tools.**

We turn hard software problems into systems people can **use, inspect and verify** — from native interfaces and web applications to agent coordination and outcome assurance.

Our public repositories include developer previews and experiments. Each project documents what works today and what still needs validation.

## Start here

| Project | Focus |
| --- | --- |
| [UNI](https://github.com/memolabs-dev/uni-protocol) | Rust CLI and protocol for independently verifying agent outcomes against evidence. **Developer preview.** |
| [Drop](https://github.com/memolabs-dev/drop) | Local-first sharing of agent capabilities with bounded access and human consent. **Under active development.** |
| [IntentLane](https://github.com/memolabs-dev/intentlane) | iOS/macOS App Intents audits and code generation. **Developer tooling; live Siri behavior needs separate validation.** |
| [Kollio](https://github.com/memolabs-dev/kollio-mac) | Native macOS visual documents and reviewable AI-proposed patches. **Prototype.** |
| [Cuesheet](https://github.com/memolabs-dev/cuesheet) | Portable primitives for orchestration and independent verification. **Research and development.** |
| [Navirox](https://github.com/memolabs-dev/navirox) | Web-to-native mobile tooling, initially focused on Vue. **Under development.** |

## Our approach

A green test suite is useful evidence, not proof of readiness for an external user. We favor reproducible examples, comprehensible interfaces and explicitly stated limitations.
